## 1. 起動と画面構成

アプリを起動すると以下の 3 つの主要エリアが表示されます。

| エリア | 場所 | 主な操作 |
|---|---|---|
| **原稿入力** | 左カラム | テキスト入力・ファイル読み込み・段落ナビ |
| **プレビュー／辞書** | 右カラム上〜中 | 辞書補正後確認・辞書 CRUD |
| **再生操作** | 右カラム下 | 読み上げ・音声保存・パラメータ調整 |

ウィンドウ中央の縦スプリッターや各パネル間の横スプリッターをドラッグして比率を変更できます。

## 2. 原稿を入力する

### 直接入力

左カラムの原稿入力欄にテキストを貼り付けるか直接入力します。

### ファイルから読み込む

- ヘッダーの **「ファイルを開く」** ボタン（Ctrl+O）、またはメニュー **ファイル → テキストファイルを開く** をクリック
- `.txt` ファイルを選択します（Shift_JIS / UTF-8 対応）
- ウィンドウへのファイルドラッグ＆ドロップにも対応しています

> **ヒント**: 入力欄に既存のテキストがある場合は置き換え確認ダイアログが表示されます。

### 段落ナビゲーション

原稿が複数の段落（空行区切り）に分かれている場合、ヘッダーの **「◀ 段落」「段落 ▶」** ボタン（Alt+↑/↓）で段落を順番に選択できます。選択後に F5 を押すと選択範囲のみ読み上げます。

### セクションナビゲーション

見出し行（■、◆、「第N章」など）が検出されると、入力欄の上部にセクションドロップダウンが表示されます。

- ドロップダウンで見出しを選択するとその行にジャンプします
- **「▶ 再生」** ボタンでそのセクション全体を読み上げます
- Alt+Shift+↑/↓ でセクション間を移動できます

## 3. 辞書補正プレビューを確認する

原稿入力後、右カラム上部のプレビューエリアで辞書適用後のテキストを確認できます。

### プレビューを更新する

- フッターの **「辞書を適用してプレビュー更新 (Ctrl+P)」** ボタン、または
- **「自動更新」** チェックボックスを ON にすると入力中に自動更新されます（500ms デバウンス）

### 変換箇所の確認

- 変換された箇所は黄色でハイライト表示されます
- **「◀ ▶」** ボタン（Alt+←/→）で変換箇所間をナビゲートできます
- 表示モード切替:
  - **【変換箇所を表示】** — 元表記→読み の形式で変換箇所を明示
  - **読み上げ用テキストのみ** — 実際に読み上げるテキストのみ表示

### 比較表示

プレビューヘッダーの **「比較表示」** チェックボックスを ON にすると、辞書適用前後のテキストを左右に並べて比較できます。

## 4. 読み上げる

### 基本操作

| ボタン | キー | 動作 |
|---|---|---|
| ▶ 読み上げ開始 | F5 | 読み上げを開始 |
| ⏸ 一時停止 | F6 | 読み上げを一時停止 |
| ▶ 再開 | F7 | 一時停止から再開 |
| ⏹ 停止 | F8 | 読み上げを停止 |

### 選択範囲のみ読み上げる

原稿入力欄でテキストを選択（ドラッグ等）してから F5 を押すと、選択した範囲のみ読み上げます。

### 読み上げ位置ハイライト

「読み上げ中の位置を蛍光色でハイライト表示する」チェックボックスを ON にすると、読み上げ中の位置が蛍光イエローで強調表示されます。

> SSML モード有効時はハイライト機能が無効になります。

### 速度・音量の調整

- **速度** スライダー: -10（最遅）〜 0（標準）〜 +10（最速）
- **音量** スライダー: 0（無音）〜 100（最大）

### SSML モード（自動ポーズ）

「句読点・改行に自動ポーズを挿入する（SSML モード）」をチェックすると、句読点（。！？、）や改行の後に自然な間が入ります。ポーズ強度は「短め」「標準」「長め」から選択できます。

## 5. 音声ファイルに保存する

### 1ファイルずつ保存

**「音声保存」** ボタン（Ctrl+S）をクリックすると保存ダイアログが開きます。WAV / MP3 / MP4(AAC) の 3 形式から選択できます。

### 一括保存

設定（ファイル → 設定）で一括保存形式（WAV・MP3・MP4 の組み合わせ）を選択しておくと、**「一括保存」** ボタンで複数形式を同時に保存できます。

### 保存ファイル名の設定

設定 → 「音声保存ファイル名」で命名テンプレートを設定できます。

| 変数 | 内容 |
|---|---|
| `{prefix}` | 設定したプレフィックス文字列 |
| `{date}` | 保存日（yyyyMMdd） |
| `{time}` | 保存時刻（HHmmss） |
| `{datetime}` | 保存日時（yyyyMMdd_HHmmss） |
| `{title}` | 原稿の先頭行 |

## 6. 読み替え辞書を管理する

右カラム中段の辞書一覧で読み替えルールを管理します。

### エントリの追加

- **「追加」** ボタン（Ins）でダイアログを開き、表記・読み・備考・優先度を入力します

### エントリの編集

- **セルを直接クリック** または **F2** でインライン編集
- **ダブルクリック** または **「編集」** ボタンでダイアログ編集（優先度も変更可）

### エントリの削除

- 1件選択して **「削除」** ボタン（Del）
- 複数選択して一括削除も可能

### 上下移動（優先度順の調整）

- **「↑」「↓」** ボタンまたは **Ctrl+Shift+↑/↓** で選択エントリを上下に移動します
- 絞り込み中は移動できません

### 一括優先度変更

複数のエントリを選択して **「優先度変更」** ボタンを押すと、選択したすべてのエントリの優先度を一括変更できます。

### 元に戻す

一括削除または一括優先度変更の直後であれば **「元に戻す」** ボタンで操作を取り消せます（1段階のみ）。

### 絞り込み

辞書一覧上部の絞り込み欄に文字を入力すると、表記・読み・備考で部分一致絞り込みができます。**「×」** ボタンでクリアします。

### CSV インポート／エクスポート

- **「CSV読込」** または メニュー「辞書 → CSV インポート」でCSVファイルを読み込めます
- **「CSV出力」** または メニュー「辞書 → CSV エクスポート」でCSVとして書き出せます

CSV 形式: `表記,読み,備考,優先度` （ヘッダー行あり・BOM 付き UTF-8）

## 7. テンプレートを使う

よく使う原稿パターンをテンプレートとして登録しておくと、ワンクリックで挿入できます。

### テンプレートの挿入

**「テンプレート」** ボタン（Ctrl+T）またはメニュー「ファイル → テンプレート」でテンプレート管理ダイアログを開きます。

- 一覧からテンプレートをダブルクリック（または「挿入」）すると原稿欄に挿入されます
- テンプレートにプレースホルダ `{変数名}` が含まれる場合は、挿入時にダイアログで値を入力します

### テンプレートの登録・編集

テンプレート管理ダイアログの **「追加」** ボタンで新規作成、**「編集」** ボタンで既存を編集します。

### お気に入りピン留め

テンプレートに★マークを付けると一覧の先頭に固定されます。

### テンプレートの検索

テンプレート管理ダイアログの検索欄でタイトル・内容を部分一致で絞り込めます。

### 予約変数

テンプレート本文に以下の変数を使うと挿入時に自動置換されます。

| 変数 | 置換内容 |
|---|---|
| `{today}` | 今日の日付（yyyy年M月d日） |
| `{now}` | 現在時刻（HH時mm分） |
| `{month}` | 現在の月（M月） |
| `{year}` | 現在の年（yyyy年） |
| `{weekday}` | 今日の曜日（月曜日 等） |

## 8. 読み上げキューを使う

複数の原稿を順番に読み上げたい場合にキューを使います。

### キューへの追加

**「＋ キュー」** ボタンで現在の原稿（選択中は選択範囲）をキューに追加します。同じテキストは重複追加されません。

### キューの再生

**「▶ 順次再生」** ボタンでキュー内のアイテムを順番に読み上げます。再生中は **「⏹ 停止」** で中断できます。

### キューの操作

- **「↑」「↓」** ボタン: 選択アイテムを上下に移動
- **「削除」** ボタン（Del キー）: 選択アイテムを削除（複数選択可）
- **「クリア」** ボタン: キュー全体を消去

### キューの永続化

設定 → 詳細タブ → 「読み上げキューを保存する」を ON にすると、アプリ終了後もキューの内容が保存されます。

---

## 9. 読み上げ履歴を使う

読み上げた原稿は直近 20 件まで履歴に記録されます（設定で無効化可能）。

### 履歴の操作

| ボタン | 動作 |
|---|---|
| **原稿へ** | 選択した履歴を原稿入力欄に復元 |
| **＋ キュー** | 選択した履歴をキューに追加 |
| **クリア** | 履歴をすべて削除 |

---

## 10. 再生プロファイルを使う

音声・速度・音量・SSML 設定の組み合わせを「プロファイル」として保存できます。

### プロファイルの保存

設定したい音声・速度・音量・SSML を調整してから、**「保存」** ボタンでプロファイル名を入力して保存します。

### プロファイルの適用

プロファイルドロップダウンから名前を選択すると、保存されていた設定が一括で適用されます。

### プロファイルの削除

使わなくなったプロファイルは **「削除」** ボタンで削除します。

---

## 11. 保存プリセットを使う

音声保存の設定（形式・フォルダ・ファイル名）を「保存プリセット」として登録できます。

### プリセットの登録

**「登録」** ボタンで名前・形式・保存フォルダを設定して保存します。

### プリセットで保存する

保存プリセットドロップダウンからプリセットを選択し、**「保存実行」** ボタンでそのプリセットの設定で即時保存します。

## 12. 設定を変更する

メニュー **ファイル → 設定** またはメニューの「設定」項目で設定ダイアログを開きます。

### 基本タブ

| 項目 | 説明 |
|---|---|
| 音声エンジン | Windows SAPI / Windows WinRT / OpenJTalk から選択 |
| 音声保存ファイル名 | プレフィックス・命名テンプレートの設定 |
| 一括保存形式 | 一括保存で出力する形式（WAV/MP3/MP4の組み合わせ） |

### 詳細タブ

| 項目 | 説明 |
|---|---|
| 前回のテキストを保存する | 起動時に前回の原稿を復元するか |
| 最近使ったファイルを記録する | ファイルメニューに履歴を表示するか |
| 終了時に機微データを消去する | 終了時にテキスト・ファイル履歴を削除するか（監査モード） |
| 終了時にログを削除する | 終了時にログファイルを削除するか |
| 監査ログ保持期間 | 監査 CSV を何ヶ月分保持するか |
| 行番号を表示する | 原稿入力欄に行番号を表示するか |
| 読み上げキューを保存する | アプリ終了後もキューを保持するか |

## 13. 読みルールを編集する

テキスト変換ルール（正規表現ベースの前処理）を編集します。辞書とは独立した変換処理です。

メニュー **ファイル → 読みルール** または Ctrl+L で読みルールダイアログを開きます。

- **「追加」** ボタン: 新しいルールを追加
- **「編集」** ボタン: 選択したルールを編集
- **「削除」** ボタン: 選択したルールを削除
- **「↑」「↓」** ボタン: ルールの適用順を変更

ルール定義は `Data/text_rules.json`（アプリフォルダ内）または `%LOCALAPPDATA%\TxtToVoice\text_rules.json`（ユーザー保存版）に保存されます。

## 14. 運用パックのエクスポート／インポート

辞書・テンプレート・設定をまとめて ZIP ファイルに書き出したり、別の端末に展開したりできます。

### エクスポート

メニュー **ファイル → 運用パック エクスポート** で ZIP ファイルの保存先を指定します。

### インポート

メニュー **ファイル → 運用パック インポート** で ZIP ファイルを選択します。

> **注意**: インポートを実行すると現在の辞書・テンプレート・設定が上書きされます。事前にエクスポートしてバックアップしてください。

## 16. データ保存先とファイル構成

### 通常モード

```
%LOCALAPPDATA%\TxtToVoice\
├── settings.json       アプリ設定
├── dictionary.json     読み替え辞書
├── templates.json      原稿テンプレート
├── profiles.json       再生プロファイル
├── save_presets.json   保存プリセット
├── queue.json          読み上げキュー（永続化 ON 時）
├── text_rules.json     ユーザー保存の読みルール（保存時のみ生成）
├── audit_YYYYMM.csv    監査ログ（月次ローテーション）
└── logs\               アプリログ
```

### ポータブルモード

EXE と同じフォルダに `portable.flag` ファイルを置いて起動すると、すべてのデータが EXE フォルダ内に保存されます（書き込み不可の場合は通常モードに自動切替）。

### バックアップ

上記フォルダを定期的にコピーするか、メニュー「ファイル → 運用パック エクスポート」で ZIP バックアップを作成することを推奨します。

## 17. トラブルシューティング

### 音声が出ない

1. 再生操作エリアの音量スライダーが 0 になっていないか確認
2. PC のシステム音量・ミュートを確認
3. 音声（ボイス）の選択が正しいか確認
4. 音声エンジンが利用可能か確認（設定ダイアログ → 音声エンジン）

### OpenJTalk が使えない

`setup_openjtalk.ps1` を管理者権限で実行してください（`TxtToVoice.exe` と同じフォルダに配置）。セットアップ完了後、設定ダイアログで「OpenJTalk」を選択します。

### 辞書が正しく読み込まれない

メニュー「辞書 → サンプル辞書を読み込む」でサンプルを復元できます。  
`dictionary.json` が破損している場合はバックアップと差し替えてください。

### 設定・辞書の保存に失敗する

ステータスバーにエラーコード（例: `TTV-E-IO-001`）が表示されます。ディスク容量や書き込み権限を確認してください。ログファイル（上記 16 節参照）に詳細が記録されています。

### ポータブルモードに切り替えたい

1. `TxtToVoice.exe` と同じフォルダに `portable.flag`（空ファイル）を作成
2. アプリを再起動
3. メニュー「ヘルプ → バージョン情報」で「ポータブルモード」と表示されれば成功
