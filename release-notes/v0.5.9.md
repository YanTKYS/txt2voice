# 声の広報 テキスト読み上げツール v0.5.9

読みルール保存先フォールバック・プレビューデバウンス・容量ガードなど運用品質改善リリース。

## インストール方法

1. `TxtToVoice-v0.5.9-win-x64.zip` を展開して `TxtToVoice.exe` を実行してください
2. OpenJTalk エンジンを使う場合は同梱の `setup_openjtalk.ps1` を実行してください（初回のみ）

## 変更内容

### 新機能・改善

- **読みルール保存先フォールバック**（#フォールバック）
  - Program Files など EXE フォルダへの書き込みができない環境でも、読みルール画面の「保存して閉じる」が `%LOCALAPPDATA%\TxtToVoice\text_rules.json` に自動でフォールバック保存されるようになりました
  - 次回起動時もフォールバック保存済みのファイルが優先して読み込まれます

- **読みルール保存後の即時反映**
  - 読みルール画面で保存すると、再生停止中であればエンジンが即時再起動し変更が即座に反映されます（再生中の場合は次回再起動時に反映）

- **テスト入力プレビューのデバウンス改善**
  - テスト入力欄を高速タイプしても UI が詰まらないよう、Regex 評価をバックグラウンドスレッドで 300ms デバウンス処理するようにしました

- **辞書インポート容量ガード**（#70）
  - CSV インポート時にエントリ数 1,000 件超または総表記文字数 10,000 文字超の場合、続行確認ダイアログを表示します（「はい」で続行可能）

- **監査ログのタイムゾーン明示**
  - `audit.csv` の timestamp が `+09:00` 形式のUTCオフセット付き ISO 8601 形式になりました（例: `2026-04-26T14:30:00+09:00`）

### 内部変更

- `PathConfig.UserTextRulesPath` / `PathConfig.EffectiveTextRulesPath` プロパティを追加
- `OpenJTalkEngine` のルール読み込みを `EffectiveTextRulesPath` に変更
- `AuditLogger`: `DateTime.Now` → `DateTimeOffset.Now`（タイムゾーンオフセット付き）

### 互換性

既存の `dictionary.json` / `text_rules.json` / `settings.json` はそのまま使用できます。  
`audit.csv` の timestamp フォーマットが変わりますが、ISO 8601 準拠のため既存ツールでも問題なく処理できます。
