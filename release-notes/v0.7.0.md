# 声の広報 テキスト読み上げツール v0.7.0

設定画面の基本/詳細タブ分離・読みルール上下移動（#101, #102）。

## インストール方法

1. `TxtToVoice-v0.7.0-win-x64.zip` を展開して `TxtToVoice.exe` を実行してください
2. OpenJTalk エンジンを使う場合は同梱の `setup_openjtalk.ps1` を実行してください（初回のみ）

## 変更内容

### 機能改善

- **設定ダイアログを「基本」「詳細」タブに分離** (#101)
  - **基本タブ**: 音声エンジン選択 / 音声保存ファイル名プレフィックス
  - **詳細タブ**: 機微データ保存ポリシー / 監査ログ保持期間
  - 設定項目の増加に伴い、利用頻度の高い設定と運用・監査向け設定を分離しました
  - ウィンドウ高さを 650 → 500 に縮小しました（1タブあたりの表示量が減ったため）

- **読みルール画面に上下移動ボタンを追加** (#102)
  - 読みルールは上から順に適用されるため、順序の変更が必要な場面に対応しました
  - 「↑」「↓」ボタンで選択中のルールを1つ上/下に移動できます
  - `Ctrl+Shift+↑` / `Ctrl+Shift+↓` キーボードショートカットにも対応しました
  - 「↑」「↓」ボタンは行選択時のみ有効化されます
