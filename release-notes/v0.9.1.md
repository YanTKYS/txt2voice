# v0.9.1 リリースノート

## バグ修正・例外処理強化

### 高優先度

- **OnSpeakProgress — absStart クランプ防御**
  テキスト変更と読み上げ進捗通知が競合した際に `absStart` が `TxtInput.Text.Length` を超え `ArgumentOutOfRangeException` になり得る問題を修正。
  `total` を先に取得し `Math.Clamp(absStart, 0, total)` で範囲を保証するよう変更。

- **TemplateViewModel._content / _title null 防御**
  `templates.json` のデータが破損していた場合に `Content` / `Title` が null になり `Preview` プロパティで `NullReferenceException` になり得る問題を修正。
  コンストラクタで `?? string.Empty` を適用し、`Preview` プロパティも null 安全に書き直し。

- **ProfileService.Save / SavePresetService.Save の未捕捉例外**
  UI イベントハンドラから直接呼んでいた `ProfileService.Save` / `SavePresetService.Save` に `try-catch` を追加。
  失敗時は `TTV-E-IO-001` / `TTV-E-IO-002` でログ出力とステータスバー通知。

- **設定保存（通常時・終了時）の try-catch 統一**
  - `Window_Closing` の `_settingsService.Save`: 失敗時は `TTV-E-IO-003` でログ出力（終了処理は継続）
  - `SaveCurrentSettings()` の `_settingsService.Save`: 失敗時は `TTV-E-IO-003` でログ出力とステータスバー通知

- **4つの永続化 Service — Save メソッドに try-catch 追加**
  `ProfileService` / `SavePresetService` / `QueuePersistenceService` / `TemplateService` の各 `Save` メソッドに
  try-catch(ログ出力 + rethrow) を追加。エラーコードを Service 層から付与する二段構えに統一。

- **CreateDirectory null-forgiving 解消（6箇所）**
  `ProfileService` / `SavePresetService` / `QueuePersistenceService` / `TemplateService` / `TextRuleLoader` / `AuditLogger` で
  `Path.GetDirectoryName(filePath)!` を `string? dir + IsNullOrEmpty チェック` パターンに統一。

### 中優先度

- **TtvErrorCode 拡張**
  - `TTV-E-IO-001` … 再生プロファイル保存失敗
  - `TTV-E-IO-002` … 保存プリセット保存失敗
  - `TTV-E-IO-003` … アプリ設定保存失敗
  - `TTV-E-IO-004` … テンプレート保存失敗
  - `TTV-E-IO-005` … 読み上げキュー保存失敗
  - `TTV-E-IO-006` … CSV エクスポート失敗
  - `TTV-E-UI-001` … DispatcherUnhandledException（未ハンドル UI 例外）

- **CsvService.Export に try-catch + TTV-E-IO-006 追加**
  `File.WriteAllText` を try-catch で包み、失敗時に `TTV-E-IO-006` でログ出力 + rethrow。
  呼び出し元（DictionaryOperations）の既存 catch でユーザー通知される二段構え。

- **WinRtSpeechEngine — 音声ファイル保存ブロックに catch 追加**
  `File.Copy` / エンコード処理の try ブロックに catch を追加。
  `OperationCanceledException` は透過させ、その他の IO 例外は `TTV-E-SAVE-001` でログ出力 + rethrow。

- **TemplateManagerDialog.AutoSave にエラーコード付与**
  既存の try-catch に `TTV-E-IO-004` を追加し、ログとダイアログ文言に反映。

- **DispatcherUnhandledException に TTV-E-UI-001 を付与**
  グローバル例外ダイアログのログ出力とメッセージボックス文言に `TTV-E-UI-001` を追記。

### 低優先度

- **一時ファイル削除失敗を Logger.Warn に格上げ**
  `JsonPersistenceService` / `AppSettingsService` の保存失敗時 tmp クリーンアップで
  `catch { /* 無視 */ }` を `catch (Exception ex) { Logger.Warn(...) }` に変更し、
  ディスク残存の把握を容易にした。
