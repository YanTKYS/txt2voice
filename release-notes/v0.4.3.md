# 声の広報 テキスト読み上げツール v0.4.3

## インストール方法

1. `TxtToVoice-v0.4.3-win-x64.zip` を展開して `TxtToVoice.exe` を実行してください
2. OpenJTalk エンジンを使う場合は同梱の `setup_openjtalk.ps1` を実行してください（初回のみ）

## 変更内容

### 改善

- **OpenJTalk: TextPreprocessor フェーズ2（#50）**
  - 全角数字 `０-９` → 半角に正規化（例: `３月` → `さんがつ`）
  - 全角パーセント `％` → `パーセント`（例: `１０％` → `10パーセント`）
  - `〒` → `ゆうびんばんごう`
  - `℃` → `ど`
  - `㎡` → `へいほうめーとる`
  - ゴールデンサンプルテスト 27 件（フェーズ2分を追加）

- **TextPreprocessor を TxtToVoice.Core へ移設**
  - `net8.0`（OS 非依存）プロジェクトに移設し CI で常時テスト可能に
  - `TxtToVoice.Core.Tests` でフェーズ1+2 の全テストをカバー

- **CI ワークフロー: 失敗原因の個別表示**
  - セットアップ未完了時のサマリーに DLL 欠落・辞書欠落・音声モデル欠落を個別に表示
  - 復旧作業の起点を特定しやすくなりました
