# 声の広報 テキスト読み上げツール v0.5.1

SourceForge Cloudflare 恒久対応（#49b）リリース。

## インストール方法

1. `TxtToVoice-v0.5.1-win-x64.zip` を展開して `TxtToVoice.exe` を実行してください
2. OpenJTalk エンジンを使う場合は同梱の `setup_openjtalk.ps1` を実行してください（初回のみ）
   - v0.5.1 以降は `mei_normal.htsvoice` が GitHub Release asset として提供されます
   - SourceForge Cloudflare 制限の影響を受けずに自動セットアップが完了します

## 変更内容

### 改善（#49b）

- **SourceForge Cloudflare 恒久対応 — GitHub Release asset 方針**
  - `mei_normal.htsvoice`（CC BY 3.0・THIRD_PARTY_LICENSES.txt にクレジット記載済み）を
    GitHub Release asset として配布開始
  - `setup_openjtalk.ps1` の音声モデル取得優先順位を更新:
    1. 同梱 `bundled\mei_normal.htsvoice`（既存）
    2. **GitHub Release 直接ダウンロード**（~25MB・新規追加）
    3. SourceForge ZIP ミラー 4 候補（~200MB・フォールバック）
  - SourceForge の Cloudflare JS チャレンジによる失敗を実質解消
  - 失敗時の手動手順メッセージも GitHub Release を「手順A」として案内するよう更新

### CI 改善

- **`release.yml`**:
  - 音声モデル取得ステップを追加（前バージョン asset 転用 → SourceForge ダウンロードの 2 段構え）
  - `mei_normal.htsvoice` を ZIP と並べて release asset としてアップロード（`continue-on-error: true`）

- **`openjtalk-engine-test.yml`**:
  - `mei_normal.htsvoice` の直接キャッシュ（~25MB）を追加し ZIP キャッシュ（~200MB）と 2 段構えに
  - コメントを更新してダウンロード優先順位を明記
