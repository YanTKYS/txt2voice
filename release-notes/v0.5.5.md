# 声の広報 テキスト読み上げツール v0.5.5

設定ダイアログでのエンジン切替を再生停止中に限り即時反映するよう改善（#58）リリース。

## インストール方法

1. `TxtToVoice-v0.5.5-win-x64.zip` を展開して `TxtToVoice.exe` を実行してください
2. OpenJTalk エンジンを使う場合は同梱の `setup_openjtalk.ps1` を実行してください（初回のみ）

## 変更内容

### 機能改善（#58）

- **設定ダイアログでエンジン種別を変更した際、再生停止中であれば即時切替**
  - 従来: 変更は次回起動時に反映
  - 改善後: `PlaybackState.Idle`（再生停止中）に限り、ダイアログを閉じた直後にエンジンが切り替わる
  - 再生中・一時停止中は従来どおり次回起動時に反映（安全ガード）
  - 切替後はボイス一覧・レート・ボリュームを新エンジンの値に自動再適用

### 内部変更

- `SpeechService`: `_engine` フィールドから `readonly` を除去し、`ReplaceEngine(ISpeechEngine)` メソッドを追加
- イベントハンドラを匿名ラムダから名前付きメソッド（`OnEngineStarted` / `OnEngineCompleted` / `OnEngineProgress` / `OnEngineError`）に変換
- `AttachEngine()` / `DetachEngine()` ヘルパーでイベント着脱を一元管理（Dispose でも使用）
- `MainWindow.SettingsOperations`: `MenuSettings_Click` にエンジン切替ガードを追加

### 互換性

既存の辞書ファイル・設定ファイルはそのまま使用できます。動作に変化はありません。
