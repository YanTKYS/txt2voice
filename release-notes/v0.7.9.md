# v0.7.9 リリースノート

## 新機能

### #121 テンプレート予約変数
- テンプレートのプレースホルダに `{today}` `{now}` `{month}` `{year}` `{weekday}` を使用すると、挿入ダイアログで現在日時の値が自動入力される
  - `{today}` = 「2026年4月29日」形式
  - `{now}` = 「14:30」形式
  - `{month}` = 「4月」形式
  - `{year}` = 「2026年」形式
  - `{weekday}` = 「水曜日」形式
- 値は編集可能なため、自動入力後に手動で変更することも可能

### #120 テンプレート利用履歴
- テンプレートを挿入するたびに「最終使用日時」と「使用回数」が自動更新される
- TemplateManagerDialog に「最近使った順」「タイトル順」「使用回数順」のソート切替 ComboBox を追加
  - デフォルトは「最近使った順」（未使用テンプレートは末尾）
- 一覧に「最終使用」「使用回数」列を追加
