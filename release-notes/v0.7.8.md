# v0.7.8 リリースノート

## 新機能

### #116 セクション再生（#113 の拡張）
- セクションナビのドロップダウンでセクションを選択すると「▶ 再生」ボタンが有効化
- クリックするとそのセクションのテキスト（次の見出しまたはファイル末尾まで）を選択して読み上げ開始

### #117 辞書一括操作 Undo（1段）
- 辞書ツールバーに「元に戻す」ボタンを追加
- 一括削除または優先度一括変更の直前の状態に戻せる（1操作のみ）
- 追加・編集・インライン編集・CSV インポート後はスナップショットを破棄（不整合防止）

### #118 運用パック入出力
- ファイルメニューに「運用パック エクスポート」「運用パック インポート」を追加
- エクスポート：辞書・テンプレート・設定（機微データ除去済み）を ZIP にまとめて書き出す
  - ユーザー定義の読みルール（text_rules.json）が存在する場合は自動で含める
- インポート：ZIP から辞書・テンプレート・設定を一括で上書き読み込み
  - 含まれるファイル一覧を確認してから適用
  - 読み込み後に辞書・設定を自動再適用

## UX 改善

### 一括保存サマリ強化
- 一括保存完了時にコピー可能なダイアログ（BatchSaveResultDialog）を表示
- 保存先ファイルパスをクリップボードにコピーできる「パスをコピー」ボタンを追加
- 形式ごとのエラー情報も同一ダイアログに表示
