## 安定化・監査機能強化リリース — キャンセル安全性修正・ログ管理強化・ポータブル自動フォールバック

---

### インストール方法

1. `TxtToVoice-v0.2.3-win-x64.zip` をダウンロード
2. ZIP を任意のフォルダに展開
3. `TxtToVoice.exe` をダブルクリックして起動

> 辞書データ・設定ファイルは引き続き使えます。

---

### 変更内容

**1. 音声保存キャンセルの安全性修正（バグ修正）**

キャンセル操作が確実に効かないケースを 3 件修正しました。

| 修正箇所 | 内容 |
|---|---|
| `ManualResetEventSlim.Wait()` | `done.Wait()` → `done.Wait(ct)` に変更。音声エンジンが `SpeakCompleted` を発火しないまま停止した場合、キャンセルボタンを押しても永久にブロックされる問題を修正。 |
| `SpeakCompleted` コールバック | `done.Set()` を `try/catch(ObjectDisposedException)` で保護。`ManualResetEventSlim` 解放後にエンジンが `SpeakCompleted` を発火してもクラッシュしなくなった。 |
| NAudio エンコード後 | `EncodeToMp3` / `EncodeToAac` の直後に `ct.ThrowIfCancellationRequested()` を追加。エンコード開始後にキャンセルしても、完了後に正しく検知して書きかけファイルを削除できるようになった。 |

**2. 監査モードのログ管理を強化（設定ダイアログ改善）**

「設定」ダイアログに 2 つの監査向け動作を追加しました。

**(B) INFO ログ抑制**
「終了時に入力テキスト・ファイル履歴を消去する（監査向け）」をオンにすると、
INFO レベルのログ書き込みを抑制します（WARN / ERROR は引き続き記録されます）。

**(C) ログファイル削除オプション**
「終了時にログファイルも削除する（監査向け・強化オプション）」チェックボックスを追加しました。
「消去する」がオンのときに限り有効となり、終了時にその日のログファイルを削除します。

> チェックボックスの有効/無効が連動しており、「消去する」がオフの状態では「ログも削除」は操作できません。

**3. ポータブルモードの自動フォールバック（動作改善）**

`portable.flag` が存在するが EXE フォルダへの書き込みができない場合（読み取り専用フォルダ等）、
起動時に **自動的に通常モード（`%LOCALAPPDATA%`）へ切り替える**ようになりました。

```
portable.flag が見つかりましたが、EXE フォルダへの書き込みができません。

辞書・設定・ログは通常の保存先（%LOCALAPPDATA%\TxtToVoice）に自動切替されました。

保存先: C:\Users\<ユーザー名>\AppData\Local\TxtToVoice

ポータブルモードを使う場合はフォルダのアクセス権限を確認してください。
```

v0.2.1 では「書き込みできない」という警告のみでそのまま続行していましたが、
今バージョンからはサイレントに失敗することなく、安全な保存先へ自動切替します。

**4. バージョン情報ダイアログの改善**

「ヘルプ」→「バージョン情報」に動作モードを表示するようになりました。

| 動作状態 | 表示 |
|---|---|
| 通常モード | （表示なし） |
| ポータブルモード | `動作モード: ポータブルモード（EXEフォルダ内にデータ保存）` |
| 自動フォールバック | `動作モード: 通常モード（ポータブル要求→書込不可→自動切替）` |

**5. README 更新**

- 画面構成図にハイライトチェックボックスを追記
- 読み上げ位置ハイライト・音声保存キャンセル・ポータブルモードの操作説明を追記
- 「機微データ保存ポリシー」の設定項目一覧表を新設
- ポータブルモードと通常モードの保存先比較表を追加
- トラブルシューティングにフォールバック通知の説明を追加
