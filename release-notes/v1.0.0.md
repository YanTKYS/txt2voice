## v0.9.4 以降の変更

### UI 修正: 再生操作エリアが隠れる問題を解消

**問題**: 右カラムの GridSplitter を操作するとプレビュー・辞書エリアが拡大し、
再生ボタン群が画面外に追いやられて見えなくなる場合があった。

**修正**: 再生操作行の `RowDefinition` を `Height="1.8*" MinHeight="160"` から
`Height="Auto"` に変更。`Auto` 行は GridSplitter に圧縮されないため、
画面サイズや分割位置に関わらず再生ボタンが常に表示される。
履歴・キューの ListBox は既存の `MaxHeight="72"` で上限を維持。

### setup_openjtalk.ps1 / create-icon.ps1 — 文字化け修正

**問題**: PowerShell ISE（Windows PowerShell 5.1 + メモ帳系エディタ）で
PS1 ファイルを開くと日本語コメントが文字化けしていた。

**修正**: 両スクリプトを UTF-8 BOM 付きに変換し、`.gitattributes` に
`*.ps1 text eol=crlf` を追加して CRLF/LF の自動変換を固定。

### サンプル辞書 — 沖縄向けエントリ大幅拡充

地域特化の読み辞書として以下を追加（合計 235 エントリ）:
- 沖縄市町村名・自治体略称の読み
- 県南難読地名（糸満・豊見城・南風原 等）
- 沖縄の苗字（喜屋武・我那覇・大城 等）
- 行政用語（介護予防・認定審査会・特定健診 等）
- o-dic 参考の広報誌頻出語彙（条例・補助金・窓口 等）
