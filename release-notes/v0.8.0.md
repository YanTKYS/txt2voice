# v0.8.0 リリースノート

## 新機能

### #122 保存プリセット
- 音声保存の設定（ファイル名テンプレート・保存モード・一括保存形式・SSML ポーズ強度）をまとめてプリセットとして登録できる
- 再生コントロールバーにプリセット選択 ComboBox と「保存実行」「登録」「削除」ボタンを追加
- プリセット選択 → 「保存実行」で即座に保存ダイアログを開き、登録した設定で保存
  - 単体保存モード: 通常の音声保存ダイアログを表示
  - 一括保存モード: プリセットの形式リストで一括保存ダイアログを表示
- 同名プリセット登録時は上書き確認あり
- プリセットは `save_presets.json` に保存（運用パックに含まれる）

### #125 Alt キーショートカット拡張
- `Alt+↑/↓` で段落ナビを前後に移動
- `Alt+Shift+↑/↓` でセクションナビを前後に移動
- `Alt+←/→` でプレビューの前/次マッチにジャンプ
- TextBox のデフォルト動作と干渉しない Alt 系キーを採用

## 改善

### 運用パック (#118) に保存プリセットを追加
- エクスポート: `save_presets.json` が存在する場合に運用パックへ自動収録
- インポート: 運用パック内に `save_presets.json` があれば自動展開
