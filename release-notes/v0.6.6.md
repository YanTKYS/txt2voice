# 声の広報 テキスト読み上げツール v0.6.6

音声保存進捗の可視化・SSML ポーズ強度カスタマイズ・バグ修正（#89, #90）。

## インストール方法

1. `TxtToVoice-v0.6.6-win-x64.zip` を展開して `TxtToVoice.exe` を実行してください
2. OpenJTalk エンジンを使う場合は同梱の `setup_openjtalk.ps1` を実行してください（初回のみ）

## 変更内容

### 新機能

- **音声保存の進捗バーを確定表示に変更** (#89)
  - 合成フェーズ（30%）・エンコードフェーズ（70%）・完了（100%）を段階的に表示します
  - パーセンテージ数値も合わせて表示するようにしました

- **SSML ポーズ強度カスタマイズ（短め / 標準 / 長め）** (#90)
  - SSML モード有効時に再生操作パネルの「ポーズ強度」コンボボックスで調整できます
  - **短め**（0.5x）: 句点300ms / 読点100ms / 改行200ms / 空行400ms
  - **標準**（既定）: 句点600ms / 読点200ms / 改行400ms / 空行800ms
  - **長め**（1.5x）: 句点900ms / 読点300ms / 改行600ms / 空行1200ms
  - 設定は `settings.json` に保存され、次回起動時に復元されます
  - SsmlBuilderTests に強度 0・1・2 のテスト 5 件追加

### バグ修正

- **SettingsDialog の ComboBox Tag キャストバグを修正**
  - WPF XAML の `Tag="13"` は文字列型として渡されるため `(int)ci.Tag` は `InvalidCastException` を発生させる可能性がありました
  - `Convert.ToInt32(ci.Tag)` に変更し文字列・数値どちらでも正常動作するようにしました
