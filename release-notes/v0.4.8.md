# 声の広報 テキスト読み上げツール v0.4.8

## インストール方法

1. `TxtToVoice-v0.4.8-win-x64.zip` を展開して `TxtToVoice.exe` を実行してください
2. OpenJTalk エンジンを使う場合は同梱の `setup_openjtalk.ps1` を実行してください（初回のみ）

## 変更内容

### 新機能

- **辞書一覧リアルタイム絞り込み（#64）**
  - 辞書一覧の上部に「絞り込み」入力欄を追加
  - 表記・読み・備考に対して部分一致フィルターをリアルタイム適用
  - 「×」ボタンでフィルターを即座にクリア
  - フィルター中はカウントを「X / N 件（フィルター中）」と表示
  - 大文字小文字区別なし（英数字混在の辞書エントリにも対応）

### 改善

- **OpenJTalk セットアップ URL 複数候補化（#52 残）**
  - `setup_openjtalk.ps1` のダウンロードに SourceForge ミラー 4 候補を設定
    （jaist / downloads / umnmirror / excellmirror の順に試行）
  - 各試行の失敗理由をリアルタイム表示し、次候補へ自動フォールバック
  - 全候補失敗時は最後のエラーを明示して手動手順を案内
  - セットアップ完了時に「コンポーネント状態」サマリ（OK/NG）を出力
