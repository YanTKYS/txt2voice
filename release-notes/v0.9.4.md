# v0.9.4 リリースノート

## 実機検証フィードバック対応

### 1. setup_openjtalk.ps1 — jtalk.dll 配置場所の修正

**問題**: セットアップ後に `Data\openjtalk\jtalk.dll` に配置され、「TxtToVoice.exe と同じフォルダに移動してください」という手順が発生していた。

**修正**: `$dllDest` を `$scriptDir\jtalk.dll`（= TxtToVoice.exe と同じディレクトリ）に変更し、最初から正しい場所に配置するようにした。`-VerifyOnly` フラグも同じ変数を参照するため自動的に一致する。

### 2. 音声エンジン切替時の再起動ダイアログ

**問題**: 再生中にエンジンを変更した場合、変更が次回起動まで反映されないが、その説明を見落とすと原因が分からないままだった。

**修正**: `MainWindow.SettingsOperations.cs` の `MenuSettings_Click` に else ブロックを追加。再生中にエンジン種別が変わった場合、設定保存後に以下のダイアログを表示する:

```
音声エンジンを変更しました。
変更を適用するにはアプリを再起動する必要があります。

今すぐ再起動しますか？  [はい] [いいえ]
```

- **「はい」**: `Process.Start(exePath)` で新プロセスを起動し、`Application.Current.Shutdown()` で終了
- **「いいえ」**: ステータスバーに「次回起動時に反映されます」を表示

**合わせて**: `SettingsDialog.xaml` の音声エンジン説明文を実際の動作（再起動確認ダイアログ表示）に合わせて更新。

### 3. アプリアイコン生成スクリプト

**追加**: `tools/create-icon.ps1` を新規作成。

- System.Drawing を使用し、16 / 32 / 48 / 256 px の 4 サイズを持つ ICO ファイルを生成
- デザイン: アプリブルー（#2C5F8A）の角丸正方形背景に白い「声」を中央配置。32px 以上では右下に白い音波ドット 3 つを追加
- 出力先: `TxtToVoice/app.ico`
- `TxtToVoice.csproj` の `<ApplicationIcon>` を `Condition="Exists('app.ico')"` 付きで参照するよう更新

**使用方法**:
```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\tools\create-icon.ps1
git add TxtToVoice/app.ico
git commit -m "feat: アプリアイコンを追加"
```
