# 声の広報 テキスト読み上げツール v0.5.6

運用監査向け CSV ログ出力を実装（#59）リリース。

## インストール方法

1. `TxtToVoice-v0.5.6-win-x64.zip` を展開して `TxtToVoice.exe` を実行してください
2. OpenJTalk エンジンを使う場合は同梱の `setup_openjtalk.ps1` を実行してください（初回のみ）

## 変更内容

### 新機能（#59）

- **音声ファイル保存操作を監査 CSV に自動記録**
  - 保存のたびに `%LOCALAPPDATA%\TxtToVoice\audit.csv` へ 1 行追記
  - ポータブルモード時は EXE フォルダ直下に出力

- **記録される列**

  | 列 | 内容 | 例 |
  |---|---|---|
  | `timestamp` | 保存日時（ISO 8601） | `2026-04-26T14:30:00` |
  | `engineType` | 使用エンジン | `SystemSpeech` / `WinRT` / `OpenJTalk` |
  | `format` | ファイル形式 | `mp3` / `wav` / `mp4` |
  | `success` | 成功/失敗 | `true` / `false` |
  | `errorCode` | エラーコード（失敗時） | `TTV-E-SAVE-001` |
  | `fileHash` | ファイル名の SHA-256 先頭 8 文字（成功時） | `a3f8c1d2` |

- **個人情報ゼロ方針**: ファイル名は SHA-256 ハッシュ（先頭 8 文字）のみ記録し、実パスは保持しない
- キャンセル操作は記録しない

### 内部変更

- `TxtToVoice.Core/Services/AuditLogger.cs` を新規追加
- `PathConfig.AuditLogPath` プロパティを追加
- `AuditLoggerTests.cs` で 5 件のテストを追加

### 互換性

既存の辞書ファイル・設定ファイルはそのまま使用できます。`audit.csv` は初回保存時に自動生成されます。
