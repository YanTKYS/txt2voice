# 声の広報 テキスト読み上げツール v0.7.1

原稿テンプレート機能を追加（#93）。

## インストール方法

1. `TxtToVoice-v0.7.1-win-x64.zip` を展開して `TxtToVoice.exe` を実行してください
2. OpenJTalk エンジンを使う場合は同梱の `setup_openjtalk.ps1` を実行してください（初回のみ）

## 変更内容

### 機能追加

- **原稿テンプレート機能を追加** (#93)
  - よく使う定型文をテンプレートとして登録・管理できます
  - 原稿入力パネルの「テンプレート」ボタン、またはメニュー「ファイル → テンプレート(_M)...」から呼び出せます
  - **テンプレートダイアログ**（`TemplateManagerDialog`）:
    - テンプレートの一覧表示（タイトル + 内容プレビュー）
    - 追加 / 編集 / 削除操作（各操作を即時保存）
    - 行をダブルクリックまたは「挿入して閉じる」で原稿入力欄に挿入
    - テキスト選択中に挿入すると選択部分を置換、未選択の場合はカーソル位置に挿入
  - **テンプレート編集ダイアログ**（`TemplateEntryDialog`）:
    - タイトル（最大60文字、必須）と内容（複数行）を入力
    - タイトルが空の場合は OK ボタンを無効化
  - テンプレートデータは `%LOCALAPPDATA%\TxtToVoice\templates.json` に保存します（ポータブルモード時は EXE フォルダ配下）
