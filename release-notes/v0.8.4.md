# v0.8.4 リリースノート

## 内部改善

### TD-1 SpeakAsync/SpeakSsmlAsync → Task 戻り値（再生 API awaitable 化）
- `ISpeechEngine.SpeakAsync` / `SpeakSsmlAsync` の戻り値を `void` から `Task` に変更
- 返却する Task は読み上げ完了（または停止）で完了し、エラー時はフォルトする
- `SystemSpeechEngine`（SAPI）: `TaskCompletionSource<bool>` を導入し、`SpeakCompleted` イベントで解決
- `WinRtSpeechEngine`（WinRT）: `SpeakInternalAsync` 内に TCS を追加、`MediaEnded`/`MediaFailed` で解決、`CancellationToken` を LinkedTokenSource で統合
- `OpenJTalkEngine`: `Task.Run(() => SpeakCore(...))` をそのまま返却、エラー時は例外を再スローして Task をフォルト
- `SpeechService`: 同様に Task を返す形に更新
- `MainWindow.StartSpeech()` を `async void` に変更し `await` で完了を待機
- `OnSpeakCompleted` / `OnSpeakError` イベントハンドラを廃止し、`try/catch` で完了・エラー処理を一本化
- `SpeakCompleted` / `SpeakError` のイベント購読を MainWindow から削除（二重処理を防止）
