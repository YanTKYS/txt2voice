### インストール方法

1. `TxtToVoice-v0.4.0-win-x64.zip` をダウンロード
2. ZIP を任意のフォルダに展開
3. `TxtToVoice.exe` をダブルクリックして起動

### 変更内容

**1. OpenJTalk PoC プロジェクト追加（backlog #46）**

`poc/OpenJTalkPoC/` に技術検証用コンソールプロジェクトを追加しました。
jtalkDLL + MMDAgent Mei ボイスを使った日本語テキスト → WAV 生成の実現可能性・性能・品質を確認するための PoC（概念実証）です。

**構成**

```
poc/OpenJTalkPoC/
├── NativeJTalk.cs          — jtalkDLL P/Invoke ラッパー
├── Program.cs              — 計測・検証ドライバ
├── OpenJTalkPoC.csproj     — net8.0-windows / x64
├── SETUP.md                — 必要ファイルの取得・配置手順
└── Data/openjtalk/         — jtalk.dll・辞書・音声モデルの配置先
    └── .gitkeep            — バイナリはコミット対象外
```

**検証内容**

| 項目 | 内容 |
|---|---|
| [1] 初期化時間 | jtalkDLL の初期化時間を計測（基準: 5 秒以内） |
| [2] WAV 生成 | 短文・業務文の 2 ケースでテキスト → WAV ファイル出力を確認 |
| [3] データサイズ | MeCab 辞書・音声モデル・DLL の実サイズを記録 |
| [4] 判定サマリー | 合否を ✅/❌ で表示 |
