# 声の広報 テキスト読み上げツール v0.6.9

読みルール追加・編集・削除 UI を実装（#100）。

## インストール方法

1. `TxtToVoice-v0.6.9-win-x64.zip` を展開して `TxtToVoice.exe` を実行してください
2. OpenJTalk エンジンを使う場合は同梱の `setup_openjtalk.ps1` を実行してください（初回のみ）

## 変更内容

### 機能追加

- **読みルール画面に追加・編集・削除ボタンを追加** (#100)
  - 「読みルール設定」ダイアログの上部に「追加」「編集」「削除」ボタンを追加しました
  - **追加**: 新規ルール入力ダイアログ（`TextRuleEntryDialog`）を開きます。パターン・置換後・説明・有効フラグを入力できます
  - **編集**: 選択中のルールを同ダイアログで編集します。変更は DataGrid にリアルタイム反映されます
  - **削除**: 選択中のルールを一覧から削除します。削除後は同位置（末尾の場合は末尾）を選択します
  - 「編集」「削除」ボタンは行を選択した場合のみ有効化されます
  - パターン入力欄はリアルタイムで正規表現バリデーションを行い、構文エラーがある場合は OK ボタンを無効化してエラーメッセージを表示します
  - ルールは上から順に適用されるため、列ヘッダーによるソートは無効化しています（`CanUserSortColumns="False"`）
