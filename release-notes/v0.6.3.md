# 声の広報 テキスト読み上げツール v0.6.3

監査ログ自動削除ポリシー追加リリース（#76）。

## インストール方法

1. `TxtToVoice-v0.6.3-win-x64.zip` を展開して `TxtToVoice.exe` を実行してください
2. OpenJTalk エンジンを使う場合は同梱の `setup_openjtalk.ps1` を実行してください（初回のみ）

## 変更内容

### 新機能

- **監査ログの保持期間/自動削除** (#76)
  - 設定画面に「監査ログ保持期間」セクションを追加しました
  - 保持期間: 無制限 / 3か月 / 6か月 / **13か月（既定）** / 24か月 から選択
  - 設定した期間を超えた `audit_YYYYMM.csv` を起動時および設定変更時に自動削除します
  - 「無制限」を選択すると自動削除を行いません

### 互換性

- 既存の `settings.json` に `auditRetentionMonths` が未設定の場合は 13か月（既定）が適用されます
- 既存の月次ログファイルは次回起動時に保持期間判定の対象になります
