# 声の広報 テキスト読み上げツール v0.5.8

読みルール運用 UI を追加（#67）リリース。

## インストール方法

1. `TxtToVoice-v0.5.8-win-x64.zip` を展開して `TxtToVoice.exe` を実行してください
2. OpenJTalk エンジンを使う場合は同梱の `setup_openjtalk.ps1` を実行してください（初回のみ）

## 変更内容

### 新機能（#67）

- **「読みルール」設定画面を追加**（ファイルメニュー → 「読みルール(_L)...」）
  - `text_rules.json` に定義されたルール一覧を DataGrid で表示
  - **有効/無効をその場で切替可能**（チェックボックスで ON/OFF）
  - 「保存して閉じる」で `text_rules.json` に書き出し

- **テスト入力プレビュー**
  - 任意のテキストを入力すると、有効なルールを順番に適用した変換結果をリアルタイム表示
  - 保存前の変更も即座にプレビューに反映

- **適用タイミング**
  - 保存後、次回エンジン起動時（エンジン切替またはアプリ再起動）から読み上げに反映

### 内部変更

- `TextRuleLoader.LoadRaw()` — disabled 含む生の TextRule リストを返す新メソッド
- `TextRuleLoader.SaveRaw()` — TextRule リストを JSON に書き出す新メソッド
- `TxtToVoice/Dialogs/TextRuleDialog.xaml` / `.xaml.cs` を新規追加

### 互換性

既存の `text_rules.json` はそのまま使用できます。
