# 声の広報 テキスト読み上げツール v0.6.0

読みルール画面の運用品質・堅牢性改善リリース（#71・#72・#73・#75）。

## インストール方法

1. `TxtToVoice-v0.6.0-win-x64.zip` を展開して `TxtToVoice.exe` を実行してください
2. OpenJTalk エンジンを使う場合は同梱の `setup_openjtalk.ps1` を実行してください（初回のみ）

## 変更内容

### 改善

- **読みルール保存後の UI 再同期** (#71)
  - 読みルール保存後にエンジンを即時再起動する際、音声リスト・速度・音量の設定が正しく反映されるよう再同期処理を追加しました

- **読みルール画面に有効ファイルパスを表示** (#75)
  - DataGrid 下段に「設定ファイル: <パス>」を表示するようにしました
  - フォールバック保存が発生した際も、どのファイルが読み込まれているかを画面上で確認できます
  - 注記文言を「保存後、再生停止中は即時反映」に更新しました

- **辞書インポート容量ガードを Reading 文字数に拡張** (#73)
  - 警告の判定に読み仮名合計文字数（10,000 文字超）を追加しました
  - ダイアログに表記文字数と読み文字数の両方を表示します

### バグ修正・品質強化

- **TextRuleDialog の CancellationTokenSource を確実に Dispose** (#72)
  - ダイアログを閉じる際に `Cancel()` + `Dispose()` を実行し、リソースリークを防止しました
  - プレビュー処理のキャンセルを `OperationCanceledException` で明示的にハンドリングするようにしました

### 互換性

既存の設定・辞書ファイルはそのまま使用できます。
