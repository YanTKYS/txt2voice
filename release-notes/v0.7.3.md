# v0.7.3 リリースノート

## 新機能

### #106 段落ナビゲーション（段落送り）
- 原稿入力エリアのヘッダーに「◀」「段落 ▶」ボタンと現在位置表示（例: `2/5`）を追加
- 段落はテキスト内の空行を除いた各行を単位とし、◀▶ で順番に選択します
- 段落を選択した状態で F5 を押すと、その段落のみ読み上げます
- テキスト変更のたびに段落リストを自動更新します

### #108 未保存変更ガード
- 「ファイルを開く」「ドラッグ&ドロップ」「最近使ったファイル」で新しいファイルを読み込む際、
  入力エリアに内容がある場合は確認ダイアログを表示します
- キャンセルすると既存の内容を保持したまま操作を中断します
- 「クリア」ボタンの確認ダイアログは既存実装を維持します
