# v1.0.1 リリースノート

## UI モダン化（業務アプリ向け外観改善）

---

### ボタンホバー色の修正（BtnDanger / BtnSuccess / BtnWarn）

**問題**: `BasedOn="{StaticResource BtnPrimary}"` + `Style.Triggers` の組み合わせでは、
親スタイルの `ControlTemplate.Triggers` が子の `Style.Triggers` より優先されるため、
赤・緑・橙ボタンのホバー色が正しく変わらずブルー（BtnPrimary のホバー色）のままだった。

**修正**: 3 つのスタイルをそれぞれ独立した `ControlTemplate`（`BasedOn` なし）に書き直し、
正しい色でホバー・押下・無効状態を表現するようにした。

---

### App.xaml — 細型スクロールバー

全ウィンドウに暗黙スタイルとして 8px 幅のスクロールバーを適用。
矢印ボタンを廃止し、角丸サムで現代的なスクロールバー外観に統一した。
縦・横両方向に対応し、ホバー時はサム色を濃くして操作箇所を明確化する。

---

### スタイル追加: BtnSecondary / BtnMini

| スタイル名 | 用途 | 外観 |
|---|---|---|
| `BtnSecondary` | コピー等の二次アクション | 青のアウトラインボタン（塗りなし） |
| `BtnMini` | 履歴・キューパネル内の小ボタン | 22px、淡青グレー背景、角丸 2px |

---

### フォントファミリーの統一

`MainWindow` の Window 要素に `FontFamily="Meiryo UI, Yu Gothic UI, MS UI Gothic"` を追加し、
メニュー・ラベル・チェックボックス等のシステム UI コントロールも和文フォントで統一した。

---

### パネルヘッダーのグラデーション化

`PanelHeader` および `SubPanelHeader` の背景色を単色から縦方向の線形グラデーションに変更し、
奥行き感と視認性を向上させた。

| スタイル | 上端色 | 下端色 |
|---|---|---|
| `PanelHeader` | `#2E6395` | `#1E4F7A` |
| `SubPanelHeader` | `#4278A0` | `#2E6390` |

---

### テキスト入力エリアのフォーカス枠

`ManuscriptBox`・`PreviewBox`・`PreviewRichBox` に `IsKeyboardFocusWithin` トリガーを追加。
フォーカス時にボーダーが `#C0C0C0` → `#2C5F8A`（1.5px）に変化し、編集中の入力欄を明確に示す。

---

### ボタンへのスタイル適用

以下のボタンにスタイルを明示的に適用し、スタイル未指定によるシステムテーマ外観を解消した。

| ボタン | 適用スタイル |
|---|---|
| BtnAddToQueue・BtnPresetExec・BtnPresetRegister | `BtnPrimary` |
| BtnCopyPreview | `BtnSecondary` |
| BtnDictFilterClear・BtnProfileSave・BtnProfileDelete | `BtnMini` |
| BtnPreviewPrev・BtnPreviewNext | `BtnMini` |
| BtnClearHistory・BtnAddHistoryToQueue・BtnRestoreHistory | `BtnMini` |
| BtnClearQueue・BtnQueueDelete・BtnQueueMoveUp・BtnQueueMoveDown・BtnPlayQueue・BtnStopQueue | `BtnMini` |

---

### DataGrid 行スタイルの改善

行ホバー（`#EDF4FB`）・選択行（`#C8DAEA`）を独自スタイルで定義し、
OS テーマのアクセントカラーに依存せず一貫した外観を提供するようにした。
セル選択時の背景を透明にして行単位のハイライトを維持する。

---

### その他の細部改善

- フッターバー（原稿入力・辞書一覧・プレビュー下部）に上端区切り線（`#C8CDD4`）を追加
- ショートカット案内ボックスを `#EEF3F9` 背景 + 青の左アクセントボーダー（`#4278A0`、3px）に変更
