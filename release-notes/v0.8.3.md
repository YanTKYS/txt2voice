# v0.8.3 リリースノート

## 新機能

### #123 プレビュー比較ペイン（辞書適用前後）
- プレビューヘッダーに「比較表示」チェックボックスを追加
- ON にすると辞書適用前（元テキスト）と辞書適用後（補正後プレビュー）を左右に並べて表示
- 中央に GridSplitter を配置し、左右のペイン幅をドラッグで調整可能
- ScrollChanged イベントで左右のスクロール位置を行同期（_syncingScroll フラグでフィードバックループを防止）
- OFF にすると補正後プレビューが全幅に戻る
- テキスト変更・辞書適用・Ctrl+P 更新のたびに左ペインを自動同期
