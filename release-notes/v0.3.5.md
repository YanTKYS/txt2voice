## 品質改善リリース — テスト拡充・ログ匿名化強化・音声選択安定化・CSV 最適化

---

### インストール方法

1. `TxtToVoice-v0.3.5-win-x64.zip` をダウンロード
2. ZIP を任意のフォルダに展開
3. `TxtToVoice.exe` をダブルクリックして起動

> 辞書データ・設定ファイルは引き続き使えます。

---

### 変更概要

backlog の優先度高（#36/#38/#39）と優先度中（#40/#41）をすべて対応しました。
機能追加は 2 件（ログ匿名化強化・音声選択安定化）で、残りはテスト拡充・内部品質改善です。

---

### 変更内容

**1. BuildAppSettings のテスト可能化（backlog #36）**

`BuildAppSettings(isExit)` は保存ポリシーの分岐が多く、UI コントロールへの直接依存のためテストが困難でした。

- `TxtToVoice/Services/AppSettingsBuilder.cs` を新規追加
  - `AppSettingsBuilder.Build(...)` — 全パラメーターを引数で受け取る純粋関数
  - `MaxPersistedInputTextLength`（10,000 文字上限）定数を公開
- `MainWindow.PlaybackOperations.cs` の `BuildAppSettings(bool isExit)` は UI から値を読んで `AppSettingsBuilder.Build` に委譲する薄いラッパーに変更
- `BuildAppSettingsTests.cs` を新規追加（15 テスト: isExit フラグ・クリアポリシー・テキスト長上限・常時保存フィールド）

**2. ログ匿名化の強化（backlog #38）**

`Logger.AnonymizePaths()` の正規表現を拡充しました。

| 対応前 | 対応後 |
|---|---|
| `[A-Za-z]:\\[^\s,"']+` 1 パターン | 4 パターン（下記） |
| 空白を含むパスを取りこぼす | シングル/ダブルクォート付きパスで空白対応 |
| UNC パス非対応 | `\\server\share\...` 形式に対応 |

追加したパターン:
1. **シングルクォート付き** — .NET 例外メッセージ（`'C:\path\file.txt'`）に多い形式、空白含むパスに対応
2. **ダブルクォート付き** — `"C:\path\file.txt"`、空白含むパスに対応
3. **クォートなしドライブレター** — 元のパターン（空白・コンマ・クォートで切る）
4. **クォートなし UNC** — `\\server\share\file.txt` 形式

`AnonymizePaths` を `internal` に変更（`InternalsVisibleTo("TxtToVoice.Tests")` で参照可能）。

**3. v0.3.4 追加機能へのテスト追加（backlog #39）**

| テストファイル | 内容 |
|---|---|
| `DictionaryServiceCacheTests.cs` | AddEntry / UpdateEntry / RemoveEntry / ReplaceAll / Load 後のキャッシュ無効化 |
| `DictionaryServiceMergeTests.cs` | HasDisplay（存在/非存在・大小文字・部分一致）/ UpdateByDisplay（上書き/非追加・優先度・キャッシュ） |
| `LoggerAnonymizeTests.cs` | AnonymizePaths（通常パス・シングルクォート・ダブルクォート・空白含む・UNC・複数パス） |
| `SpeechProgressTests.cs` | WAV / MP3 / MP4 保存時のフェーズメッセージ（`[Trait("Category", "RequiresEngine")]` で CI 除外可） |

**4. CSV 重複判定の計算量最適化（backlog #40）**

CSV インポートの重複判定を O(N × M) から O(N + M) に改善しました。

- `imported` を 2 回走査して `HasDisplay()`（線形検索）を繰り返していた処理を変更
- 既存エントリの Display を `HashSet<string>` に変換して O(1) 判定
- `imported` を 1 パスで走査し `newEntries` / `duplicates` に振り分け

**5. 音声選択の安定化（表示名ではなく ID 保存）（backlog #41）**

同名音声がある環境や OS アップデート後でも意図した音声が復元されるよう、音声の識別子を内部 ID で保存するようにしました。

- `AppSettings` に `voiceId`（内部識別子）フィールドを追加
  - WinRT: `VoiceInformation.Id` / SAPI: `VoiceInfo.Id`
  - 既存 `voiceName`（DisplayName）は後方互換のため保持
- `ISpeechEngine` に `CurrentVoiceId` プロパティと `FindVoiceNameById(string)` メソッドを追加
- `SystemSpeechEngine` / `WinRtSpeechEngine` が新しいインターフェースを実装
- 起動時の音声復元: `VoiceId` → 名前検索 → `VoiceName` フォールバックの順で試行
