# v0.7.4 リリースノート

## 新機能

### #107 辞書インライン編集
- 辞書一覧の「表記」「読み」「備考」セルを直接クリックまたは F2 キーでインライン編集できるようになりました
- 「優先順位」は引き続きダイアログでのみ変更可能です
- **ダブルクリック / 「編集」ボタン** → 従来通りダイアログで全フィールドを編集
- **セルクリック / F2** → その場でセルを直接編集（Enter で確定、Escape でキャンセル）
- 編集確定時にバリデーションを実施：
  - 「表記」「読み」の空欄を禁止
  - 「表記」の重複を禁止
- 行の編集が確定すると自動保存・Aho-Corasick 再構築・プレビュー更新を実行します
- セル編集中は Ins / Del / Ctrl+Shift+↑↓ のショートカットを無視します
