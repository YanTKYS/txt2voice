# 声の広報 テキスト読み上げツール v0.4.4

## インストール方法

1. `TxtToVoice-v0.4.4-win-x64.zip` を展開して `TxtToVoice.exe` を実行してください
2. OpenJTalk エンジンを使う場合は同梱の `setup_openjtalk.ps1` を実行してください（初回のみ）

## 変更内容

### 改善

- **OpenJTalk: TextPreprocessor フェーズ3（#50）**
  - `Xか月` / `Xヶ月` / `Xヵ月`（1〜24）→ 読み仮名（例: `3か月` → `さんかげつ`）
  - `第X回`（1〜24）→ 読み仮名（例: `第3回` → `だいさんかい`）
  - 電話番号のハイフン区切り → 「の」読み（例: `0120-123-4567` → `0120の123の4567`）
  - 日付形式（`2024-01-01`）は変換しない除外ケースも明示テスト化
  - ゴールデンサンプルテスト計 47 件（フェーズ3分を追加）

- **SAPI / WinRT: 長文 MP3/MP4 保存のメモリ最適化（#53）**
  - `SystemSpeechEngine.SaveEncoded()` の `MemoryStream` を一時 WAV ファイル経由に変更
  - 長尺原稿でのメモリピーク使用量を削減
  - キャンセル時・例外時も finally で一時ファイルを確実に削除
