# 声の広報 テキスト読み上げツール v0.4.5

## インストール方法

1. `TxtToVoice-v0.4.5-win-x64.zip` を展開して `TxtToVoice.exe` を実行してください
2. OpenJTalk エンジンを使う場合は同梱の `setup_openjtalk.ps1` を実行してください（初回のみ）

## 変更内容

### 改善

- **OpenJTalk: セットアップ自己診断機能（#52 部分対応）**
  - `setup_openjtalk.ps1 -VerifyOnly` スイッチを追加
    - jtalk.dll / MeCab 辞書 / 音声モデルの存在を `[OK]` / `[NG]` でチェックして終了
    - 終了コード: 0 = 全コンポーネント OK、1 = 不足あり
    - 端末展開前の確認や運用手順書での一次切り分けに利用可能
  - `OpenJTalkDiagnostics` レコードを追加（`DllPresent` / `DictionaryPresent` / `VoicePresent`）
  - 音声エンジン初期化エラーダイアログを改善
    - OpenJTalk 選択時: 各コンポーネントの [OK]/[NG] チェックリストを表示
    - SAPI/WinRT: 従来どおり詳細エラー文を表示
