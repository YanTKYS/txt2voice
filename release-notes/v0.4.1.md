## OpenJTalk エンジン統合・UI 対応リリース

---

### インストール方法

1. `TxtToVoice-v0.4.1-win-x64.zip` をダウンロード
2. ZIP を任意のフォルダに展開
3. `TxtToVoice.exe` をダブルクリックして起動

> 辞書データ・設定ファイルは引き続き使えます。  
> OpenJTalk エンジンを使う場合は「変更内容 1」の手順を確認してください。

---

### 変更概要

backlog #47（OpenJTalkEngine 実装・UI 統合）に対応しました。
v0.4.0 の PoC 検証結果をもとに、OpenJTalk を本体アプリの音声エンジンとして選択できるようになりました。

---

### 変更内容

**1. OpenJTalk エンジンの追加（backlog #47）**

設定ダイアログの「音声エンジン」に **OpenJTalk（日本語専用 TTS）** が追加されました。

```
設定 → 音声エンジン → OpenJTalk — 日本語専用 TTS（要セットアップ）
```

**使用前の準備（初回のみ）**

OpenJTalk エンジンは外部バイナリファイルが必要です。以下の手順で配置してください。

```
1. poc\OpenJTalkPoC\setup.ps1 を実行（jtalk.dll・辞書・音声モデルを自動取得）
2. 生成された以下のファイルを TxtToVoice.exe と同じフォルダにコピー:
     jtalk.dll
     Data\openjtalk\open_jtalk_dic_utf_8\  （辞書）
     Data\openjtalk\voice\                  （音声モデル）
3. 設定ダイアログで OpenJTalk を選択して再起動
```

ファイルが揃っていない場合は `IsAvailable = false` となり、選択しても起動時にエラーメッセージで案内します。

**機能の特徴**

| 機能 | 動作 |
|---|---|
| 読み上げ（SpeakAsync） | jtalkdll で WAV 合成 → NAudio WaveOutEvent で再生 |
| ファイル保存 | WAV 直接出力 / MP3・MP4 は MediaFoundation でエンコード |
| SSML | タグを除去してプレーンテキストとして読み上げ |
| 速度設定 | SAPI -10..10 → jtalkdll speed 0.5..2.0 に変換 |
| 音量設定 | SAPI 0..100 → jtalkdll dB (-20..0) に変換 |
| 一時停止・再開 | WaveOutEvent の Pause / Play で対応 |
| 読み上げハイライト | 非対応（jtalkdll は単語境界イベントを持たないため） |

**2. ライセンス表示対応（CC BY 3.0 義務）**

- `THIRD_PARTY_LICENSES.txt` を実行ファイルと同梱するよう csproj に追加
- バージョン情報ダイアログで OpenJTalk 選択時に HTS Voice "Mei" のクレジットを表示

```
HTS Voice "Mei" © 2009-2015 名古屋工業大学 (CC BY 3.0)
```
