# v0.7.2 リリースノート

## 新機能

### #103 再生プロファイル
- 音声・速度・音量・SSML 設定を「プロファイル」として保存・呼び出しできるようになりました
- 再生操作パネルに「プロファイル」コンボボックスと「保存」「削除」ボタンを追加
- プロファイルは `profiles.json` に保存されます（ポータブルモード対応）
- プロファイル選択時に音声・速度・音量・SSML 設定を一括適用します

### #104 プレビュー変換件数表示 + ジャンプナビゲーション
- 注釈付きプレビューモード時に変換された箇所（`【…】`）の件数をフッターに表示します
- ◀ / ▶ ボタンで変換箇所を順番にジャンプできます（`IsInactiveSelectionHighlightEnabled` で選択状態を維持）
- プレビューモード切替時・辞書適用時に自動更新されます

### #105 ショートカットキー拡張
- `Ctrl+T`: テンプレート挿入ダイアログを開く
- `Ctrl+L`: 読みルール編集ダイアログを開く
- ショートカットキー案内（画面内テキスト・ヘルプメニュー）を更新しました
