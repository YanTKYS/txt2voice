## バグ修正リリース — v0.3.0 ビルドエラー・クラッシュ修正

---

### インストール方法

1. `TxtToVoice-v0.3.1-win-x64.zip` をダウンロード
2. ZIP を任意のフォルダに展開
3. `TxtToVoice.exe` をダブルクリックして起動

> 辞書データ・設定ファイルは引き続き使えます。

---

### 変更内容

v0.3.0 に含まれていた 4 件の不具合を修正しました。機能追加はありません。

**1. WinRtSpeechEngine ビルドエラー修正**

`SpeechSynthesisStream` に存在しない `Timelines` プロパティを参照していたため、
WinRT エンジンを含む Release ビルドが失敗していました。

- `SetupProgressTimer` メソッドおよび `_progressTimer` フィールドを削除
- WinRT モードでは読み上げ箇所ハイライト（`SpeakProgress` イベント）が発火しない動作に変更
  （読み上げ・停止・保存の機能には影響なし）
- 正式な実装（`MediaPlaybackItem.TimedMetadataTracks` + `SpeechCue`）は backlog #34 として記録

**2. テストプロジェクトの TargetFramework 修正**

`TxtToVoice.Tests.csproj` が `net8.0-windows`（= `windows7.0`）のままで、
主プロジェクト（`net8.0-windows10.0.19041.0`）への `ProjectReference` が
`NU1201` で失敗していました。

- `net8.0-windows10.0.19041.0` に変更して restore・build が通るよう修正

**3. 起動時 NullReferenceException 修正（ChkHighlight / ChkSsml）**

`ChkHighlight` は XAML で `IsChecked="True"` が設定されているため、
`InitializeComponent()` 中に `ChkHighlight_Changed` が発火します。
このタイミングでは `_speechService` が未代入のため、
`SaveCurrentSettings()` 内の `_speechService.CurrentVoiceName` が
`NullReferenceException` を引き起こしていました。

- `ChkHighlight_Changed` と `ChkSsml_Changed` に `if (_speechService is null) return;` を追加
  （スライダー・コンボボックスの変更ハンドラと同じガードパターン）

**4. PreviewMode_Changed の潜在的 NullReferenceException 修正**

`RbPreviewAnnotated` は XAML で `IsChecked="True"` が設定されているため、
`InitializeComponent()` 中に `PreviewMode_Changed` が発火します。
現状は `TxtInput.Text` が空なので `_dictService` を参照せず問題は発生しませんでしたが、
将来 XAML に既定テキストが追加された場合にクラッシュする構造的な問題がありました。

- `PreviewMode_Changed` に `if (_dictService is null) return;` を追加して根本修正

### 内部変更

- `TxtToVoice/Services/WinRtSpeechEngine.cs` — `_progressTimer` フィールド・`SetupProgressTimer`・`StopProgressTimer` を削除
- `TxtToVoice/MainWindow.PlaybackOperations.cs` — `ChkHighlight_Changed` / `ChkSsml_Changed` に null ガード追加
- `TxtToVoice/MainWindow.DictionaryOperations.cs` — `PreviewMode_Changed` に null ガード追加
- `TxtToVoice.Tests/TxtToVoice.Tests.csproj` — `TargetFramework` を `net8.0-windows10.0.19041.0` に更新
- `TxtToVoice/TxtToVoice.csproj` — `<Version>` を `0.3.1` に更新
- `release-notes/v0.3.0.md` — 読み上げ進捗の説明を実際の動作（非対応）に修正、backlog #34 を追記
