# 声の広報 テキスト読み上げツール v0.4.2

## インストール方法

1. `TxtToVoice-v0.4.2-win-x64.zip` を展開して `TxtToVoice.exe` を実行してください
2. OpenJTalk エンジンを使う場合は同梱の `setup_openjtalk.ps1` を実行してください（初回のみ）

## 変更内容

### 改善

- **OpenJTalk: 数値・記号読み最適化 (TextPreprocessor フェーズ1)**
  - 月表記 `X月`（1〜12月）を読み仮名に変換（例: `3月` → `さんがつ`）
  - パーセント記号 `%` を `パーセント` に変換（例: `10%` → `10パーセント`）
  - 上記はゴールデンサンプルテスト（全パターン）で回帰を防止

- **OpenJTalk: CI ワークフロー改善 (#48)**
  - セットアップスクリプトを `tools/setup_openjtalk.ps1` に統一
  - 音声モデルキャッシュを追加（SourceForge 再ダウンロード抑止）
  - スキップ時に Passed/Failed/Skipped 件数をワークフローサマリーに表示

- **OpenJTalk: テストスキップ可視化**
  - `Xunit.SkippableFact` を導入し、エンジン未セットアップ時のスキップ理由を出力

- **セットアップ導線統一 (#49)**
  - README・設定ダイアログ・エラーメッセージ・MSBuild 警告をすべて
    `setup_openjtalk.ps1` 参照に統一

### バグ修正

- CI ワークフローのサマリーに記載していた手動配置パスが誤っていた問題を修正
  （`tools/Data/openjtalk/voice/` → `TxtToVoice/Data/openjtalk/voice/`）
