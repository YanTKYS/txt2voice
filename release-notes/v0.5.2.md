# 声の広報 テキスト読み上げツール v0.5.2

TextPreprocessor 外部ルール定義（#61）リリース。

## インストール方法

1. `TxtToVoice-v0.5.2-win-x64.zip` を展開して `TxtToVoice.exe` を実行してください
2. OpenJTalk エンジンを使う場合は同梱の `setup_openjtalk.ps1` を実行してください（初回のみ）

## 変更内容

### 新機能（#61）

- **TextPreprocessor 外部ルール定義 — `Data/text_rules.json`**
  - 変換ルールを JSON ファイルとして外部定義可能になりました
  - EXE と同じフォルダの `Data\text_rules.json` を起動時に自動読み込み
  - ルールごとに `enabled: true/false` で個別に有効/無効を切り替え可能
  - 追加・変更後はアプリを再起動するだけで反映（ソース変更・再リリース不要）

- **`text_rules.json` フォーマット**:
  ```json
  [
    {
      "pattern": "CPU",
      "replacement": "シーピーユー",
      "description": "アルファベット略語: CPU",
      "enabled": true
    }
  ]
  ```
  - `pattern`: 正規表現（`System.Text.RegularExpressions.Regex` 形式）
  - `replacement`: 置換後の文字列（正規表現グループ参照 `$1` 等も使用可能）
  - `description`: 説明（省略可・アプリ動作に影響しない）
  - `enabled`: `false` にするとそのルールをスキップ

- **同梱サンプルルール**（デフォルトはすべて `enabled: false`）:
  - CPU → シーピーユー
  - AI → エーアイ
  - SNS → エスエヌエス
  - PDF → ピーディーエフ
  - URL → ユーアールエル
  - QR → キューアール

- ファイルが存在しない・JSON 形式エラー・無効な正規表現はすべてスキップしてログに記録（アプリは正常起動）

### 内部設計

- `TxtToVoice.Core/Models/TextRule.cs` — JSON DTO
- `TxtToVoice.Core/Services/TextRuleLoader.cs` — `TextRuleLoader.Load()` + `CompiledTextRule`
- `TextPreprocessor.Apply()` に `rules?` パラメータを追加（省略可・後方互換を維持）
- `PathConfig.TextRulesPath` プロパティを追加
- `OpenJTalkEngine` の `SpeakAsync` / `SaveToFile` 両呼び出し元にルールを渡すよう更新
