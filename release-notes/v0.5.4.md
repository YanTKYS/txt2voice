# 声の広報 テキスト読み上げツール v0.5.4

辞書照合アルゴリズムを Aho-Corasick に刷新（#60）リリース。

## インストール方法

1. `TxtToVoice-v0.5.4-win-x64.zip` を展開して `TxtToVoice.exe` を実行してください
2. OpenJTalk エンジンを使う場合は同梱の `setup_openjtalk.ps1` を実行してください（初回のみ）

## 変更内容

### パフォーマンス改善（#60）

- **辞書照合アルゴリズムを Aho-Corasick に刷新**（`AhoCorasick.cs` を新規追加）
  - 従来: 辞書エントリ数 m × テキスト長 n の O(n×m) スキャン
  - 改善後: テキストを O(n + 出力数) の 1 パスで走査
  - 辞書エントリ変更時のみオートマトンを再構築（以降はキャッシュ再利用）
  - **置換結果は従来と完全に等価**（長い語句優先・優先度優先・二重置換防止の各ルールを維持）

- **外部ライブラリ依存なし** — `TxtToVoice.Core` 内の自前実装（約 100 行）
  - `AhoCorasick.Build(patterns)` — トライ木構築 + 失敗リンク BFS
  - `AhoCorasick.Search(text)` — 全マッチを `(Start, PatternIndex)` で列挙

### 内部変更

- `DictionaryService.FindReplacements()` が AC オートマトンを使用するよう変更
- `InvalidateCache()` メソッドを追加し、エントリ変更時に `_sortedCache` と `_acAutomaton` を一括クリア
- `EnsureCache()` で初回アクセス時に AC オートマトンを `_sortedCache` と同時に構築

### 互換性

既存の辞書ファイル・設定ファイルはそのまま使用できます。動作に変化はありません。
