# v0.7.7 リリースノート

## 新機能

### #113 セクションナビ（ジャンプ）
- 原稿入力エリアに「セクション」ドロップダウンを追加
- 見出し行（■/◆/●/▶/第N章・節・部/【タイトル】で始まる行）を自動検出
- ドロップダウンから見出しを選ぶとその位置へ即時ジャンプ
- 見出しが1件も検出されない場合はドロップダウンを非表示
- テキスト編集のたびに自動更新

### #114 音声一括保存
- 「一括保存」ボタンを追加（音声保存ボタンの右隣）
- 設定ダイアログ「音声保存ファイル名」に「一括保存形式」チェックボックスを追加（MP3 / WAV / MP4(AAC)）
- ファイル名（拡張子なし）を1回指定するだけで、選択した全形式を同時出力
- デフォルトは MP3 のみ（既存の単体保存と同じ形式）
- 各形式の保存進捗は個別ダイアログで表示

### #115 辞書削除・優先度変更の影響プレビュー
- 辞書エントリ削除前の確認ダイアログに「現在の原稿で X 件マッチ」を表示
- 優先度一括変更時にも同様のマッチ件数を確認ダイアログに表示
- マッチがない場合は追加情報なし（ダイアログがシンプルなまま）
