# 声の広報 テキスト読み上げツール v0.4.6

## インストール方法

1. `TxtToVoice-v0.4.6-win-x64.zip` を展開して `TxtToVoice.exe` を実行してください
2. OpenJTalk エンジンを使う場合は同梱の `setup_openjtalk.ps1` を実行してください（初回のみ）

## 変更内容

### 改善

- **エラーコード付与（#54）**
  - `TxtToVoice.Core/Services/TtvErrorCode.cs` を新規作成
    - `TTV-E-OJT-001`: jtalk.dll が見つからない
    - `TTV-E-OJT-002`: MeCab 辞書が見つからない
    - `TTV-E-OJT-003`: 音声モデルが見つからない
    - `TTV-E-OJT-004`: OpenJTalk 初期化失敗
    - `TTV-E-OJT-005`: OpenJTalk WAV 合成失敗
    - `TTV-E-SAPI-001`: SAPI エンジン初期化失敗
    - `TTV-E-WRT-001`: WinRT エンジン初期化失敗
    - `TTV-E-SAVE-001`: 音声ファイル保存失敗
  - 各エンジンの初期化エラー・合成失敗のメッセージとログにコードを付与
  - 音声保存失敗のダイアログ・ステータスバー・ログにも `TTV-E-SAVE-001` を付与
  - 問い合わせ時にコードで即座に障害箇所を特定可能に

- **ログ匿名化ハードニング（#63）**
  - `Logger.Write()` にメッセージ長キャップ（500文字）を追加
    - 原稿テキストが誤混入しても一定量以上は記録されない
    - 超過分は `…[省略]` を付加して切り捨て
  - Logger の XML コメントにログ匿名化ポリシーを明文化
    - 「原稿テキスト本文は記録しない」「メタ情報のみ（エンジン・文字数・保存パス）を対象とする」
