# 声の広報 テキスト読み上げツール v0.6.7

辞書エントリ上下移動・保存ファイル名プレフィックス設定・テスト拡充（#91, #95, #96）。

## インストール方法

1. `TxtToVoice-v0.6.7-win-x64.zip` を展開して `TxtToVoice.exe` を実行してください
2. OpenJTalk エンジンを使う場合は同梱の `setup_openjtalk.ps1` を実行してください（初回のみ）

## 変更内容

### 新機能

- **辞書エントリの上下移動ボタンを追加** (#91)
  - 辞書一覧ツールバーに「↑」「↓」ボタンを追加しました
  - 選択したエントリを1つ上または下に移動できます
  - 絞り込みフィルタが有効な場合は操作を無効にします（表示順と格納順のズレを防止）
  - 移動後は対象エントリに自動スクロール・選択を維持します

- **音声保存ファイル名プレフィックスを設定可能に** (#96)
  - 設定ダイアログに「音声保存ファイル名」グループを追加しました
  - デフォルト「kouhou」を任意の文字列（最大32文字）に変更できます
  - 実際のファイル名は `<プレフィックス>_yyyyMMdd_HHmmss.mp3` の形式になります
  - 空白のみの場合は「kouhou」にフォールバックします
  - 設定は `settings.json` に保存され次回起動時に復元されます

### テスト

- **BuildAppSettingsTests の新パラメータ対応** (#95)
  - v0.6.3〜0.6.6 で追加した 5 フィールド（`AuditRetentionMonths` / `AutoPreviewEnabled` / `AnnotatedPreviewMode` / `SsmlPauseStrength` / `SaveFilePrefix`）のテストを 7 件追加
  - テストヘルパー `Build()` に対応パラメータを追加し、各フィールドへの転送を保証

### バグ修正

- **SettingsDialog の `(int)ci.Tag` キャストバグ修正（完全版）**
  - v0.6.6 の修正がループ内の `item.Tag` のみで `BtnOk_Click` 内の `ci.Tag` に未適用でした
  - `Convert.ToInt32(ci.Tag)` に統一し、XAML `Tag="13"` の string 型でも正常動作するようにしました
