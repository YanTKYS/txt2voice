## 初回リリース

自治体職員が「声の広報」原稿の読み上げ確認・音声出力を行うためのデスクトップツールです。

---

### インストール方法

1. `TxtToVoice-v0.1.0-win-x64.zip` をダウンロード
2. ZIP を任意のフォルダに展開（`C:\Tools\TxtToVoice\` など）
3. `TxtToVoice.exe` をダブルクリックして起動

> **注意** .NET ランタイムのインストールは不要です（EXE にランタイムを同梱済み）

---

### 動作要件

| 項目 | 要件 |
|------|------|
| OS | Windows 10 / 11 |
| ランタイム | 不要（自己完結型 EXE） |
| インターネット | 不要（完全オフライン動作） |
| 音声エンジン | Windows 標準 SAPI（日本語音声パッケージが必要） |

日本語音声が利用できない場合は  
**設定 → 時刻と言語 → 音声認識 → 音声の追加** から日本語音声パッケージを追加してください。

---

### 主な機能

**原稿入力**
- テキスト直接入力・貼り付け
- `.txt` ファイル読み込み（UTF-8・Shift_JIS 自動判別）
- 辞書適用後プレビュー（変換箇所を `【元表記→読み】` 形式で表示）

**読み上げ**
- 開始 / 一時停止 / 再開 / 停止
- 速度調整（−10〜+10）
- 音量調整（0〜100）
- 複数音声エンジンの選択
- テキスト選択中に開始すると選択範囲のみ読み上げ

**辞書機能**
- 地名・役職・制度名などの誤読防止辞書
- 自治体業務向けサンプル辞書 80 件同梱
- 画面から追加・編集・削除
- CSV インポート / エクスポート（他職員との共有に便利）

**音声出力**
- スピーカー再生
- WAV ファイル保存

**ショートカットキー**

| キー | 操作 |
|------|------|
| F5 | 読み上げ開始 |
| F6 | 一時停止 |
| F7 | 再開 |
| F8 | 停止 |
| Ctrl+O | ファイルを開く |
| Ctrl+P | プレビュー更新 |
| Ctrl+S | WAV 保存 |

---

### 辞書ファイルの場所

辞書は各ユーザーの以下のパスに保存されます。

```
%LOCALAPPDATA%\TxtToVoice\dictionary.json
```

バックアップ・共有の際はこのファイルをコピーしてください。
