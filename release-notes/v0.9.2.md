# v0.9.2 リリースノート

## 文言・UX 整備

### UI 文言統一

- **段落ナビボタンのラベル非対称を修正**
  `BtnParaPrev` のラベルが "◀"（ラベルなし）だったのを "◀ 段落" に修正し、`BtnParaNext` の "段落 ▶" と表記を統一。

- **段落ナビ ToolTip にショートカットを追記**
  `BtnParaPrev` ToolTip に `(Alt+↑)`、`BtnParaNext` ToolTip に `(Alt+↓)` を明記。

### ショートカット一覧ダイアログ補完

- `Ctrl+Shift+↑/↓`（辞書エントリの上下移動）が未掲載だったため追加。
- 各説明の表記を既存 UI の文言に合わせて整理（段落ナビ・セクションナビ・プレビューナビの説明を具体化）。

### About ダイアログ整理

- パス表示を「データ保存先」ブロックとしてまとめ、**設定・辞書・テンプレート・ログ出力先** を一覧表示に変更。
- 動作モード表示を `portableNote`（`\n` 付き追記）から `modeLabel`（独立行）に変更し、常に表示するよう統一。
