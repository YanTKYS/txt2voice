# 声の広報 テキスト読み上げツール v0.6.1

監査ログの月次ローテーション対応リリース（#74）。

## インストール方法

1. `TxtToVoice-v0.6.1-win-x64.zip` を展開して `TxtToVoice.exe` を実行してください
2. OpenJTalk エンジンを使う場合は同梱の `setup_openjtalk.ps1` を実行してください（初回のみ）

## 変更内容

### 改善

- **監査ログの月次ローテーション** (#74)
  - `audit.csv` の固定ファイルから月次形式 `audit_YYYYMM.csv`（例: `audit_202601.csv`）に変更しました
  - 月が変わると自動的に新しいファイルへの書き込みに切り替わります
  - 長期運用での単一ファイル肥大化を防ぎます

### 互換性

- v0.5.9 以前に生成された `audit.csv` はそのまま残ります（新規レコードは月次ファイルに書き込まれます）
- `PathConfig.AuditLogPathForMonth(DateTimeOffset)` API を追加（アーカイブ参照用）
