# 声の広報 テキスト読み上げツール v0.6.4

UX 改善 3 点（設定文言修正・自動プレビュー・SSML/ハイライト排他）。

## インストール方法

1. `TxtToVoice-v0.6.4-win-x64.zip` を展開して `TxtToVoice.exe` を実行してください
2. OpenJTalk エンジンを使う場合は同梱の `setup_openjtalk.ps1` を実行してください（初回のみ）

## 変更内容

### 改善

- **設定ダイアログ：エンジン変更の説明文を実際の動作に合わせて修正** (#81)
  - 旧: "変更は次回起動時に適用されます"
  - 新: "エンジン変更は再生停止中に即時反映されます。再生中の場合は次回起動時に反映されます"

- **入力テキストの自動プレビュー更新トグルを追加** (#82)
  - フッターに「自動更新」チェックボックスを追加しました
  - オンにすると入力が止まってから 500ms 後にプレビューを自動更新します
  - デバウンス処理により、連続入力中は更新をスキップします

- **SSML モード ON 時にハイライトを自動無効化** (#84)
  - SSML チェックボックスをオンにすると「読み上げ中ハイライト」チェックボックスが自動でオフ＆グレーアウトされます
  - SSML をオフに戻すとハイライトが再び選択可能になります
  - 起動時の設定復元時も同様に初期状態を反映します
