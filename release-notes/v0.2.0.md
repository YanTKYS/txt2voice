## バグ修正・安定化リリース — Shift_JIS 登録一本化・ポータブルモード修正・音声保存キャンセル UI

---

### インストール方法

1. `TxtToVoice-v0.2.0-win-x64.zip` をダウンロード
2. ZIP を任意のフォルダに展開
3. `TxtToVoice.exe` をダブルクリックして起動

> 辞書データ・設定ファイルは引き続き使えます。

---

### 変更内容

**1. Shift_JIS コードページ登録の一本化（バグ修正）**

Shift_JIS テキストファイルをドラッグ&ドロップまたはファイルメニューから開く場合、
CSV インポートを事前に使っていないと `ArgumentException` が発生することがあった問題を修正しました。

`Encoding.RegisterProvider(CodePagesEncodingProvider.Instance)` を `App.OnStartup` の先頭に移動し、
アプリ起動直後に登録するよう一本化しました。

**2. ポータブルモード時の未処理例外ダイアログのログパス修正（バグ修正）**

ポータブルモード（`portable.flag` を配置した環境）で未処理例外が発生した際、
エラーダイアログのログパス案内が常に `%LOCALAPPDATA%\TxtToVoice\logs` と表示される問題を修正しました。

`PathConfig.LogDirectory` を参照するよう変更したため、ポータブルモード時は
EXE フォルダ配下の `logs` フォルダが正しく案内されます。

**3. 音声保存のキャンセル UI を追加**

長文の音声保存中に操作をキャンセルできるようになりました。

- 「保存」ボタンを押すと進捗ダイアログが表示されます
- ダイアログの「キャンセル」ボタン、または × ボタンで保存を中断できます
- キャンセル時は書きかけのファイルを自動削除します
- 音声合成エンジンへの中断シグナルを送り、ベストエフォートで速やかに処理を停止します

---

### 内部変更

- `App.xaml.cs` — `OnStartup` の先頭で `Encoding.RegisterProvider` を呼び出し（登録を一本化）
- `App.xaml.cs` — `DispatcherUnhandledException` のログパスを `PathConfig.LogDirectory` に変更
- `Services/CsvService.cs` — 静的コンストラクタを削除（登録処理を `App` 側に委譲）
- `Services/SpeechService.cs` — `SaveToFile` / `SaveWavDirect` / `SaveEncoded` に `CancellationToken` を追加、`SpeakAsync` + `ManualResetEventSlim` でキャンセル対応
- `Dialogs/SaveProgressDialog.xaml` / `.xaml.cs` を新規追加
- `MainWindow.PlaybackOperations.cs` — `SaveAudio()` に `CancellationTokenSource`・進捗ダイアログ・`OperationCanceledException` ハンドリングを追加
- `TxtToVoice.csproj` の `<Version>` を `0.2.0` に更新
