# 声の広報 テキスト読み上げツール v0.5.3

音声品質評価 CI インフラ整備（#51）＋ リリース前チェックリスト（#55）リリース。

## インストール方法

1. `TxtToVoice-v0.5.3-win-x64.zip` を展開して `TxtToVoice.exe` を実行してください
2. OpenJTalk エンジンを使う場合は同梱の `setup_openjtalk.ps1` を実行してください（初回のみ）

## 変更内容

### 音声品質評価 CI インフラ整備（#51）

- **`VoiceQualityEvalTests.cs`** を新規追加（`TxtToVoice.Tests/Services/`）
  - S1〜S4 の固定原稿を OpenJTalk エンジンで WAV 合成するテスト
  - `[Trait("Category", "VoiceQualityEval")]` フィルタで個別実行可能
  - 出力先: 環境変数 `VOICE_EVAL_OUTPUT_DIR`（未設定時は `%TEMP%\txtvoice-eval`）

- **`openjtalk-engine-test.yml`** を更新
  - RequiresEngine テスト完了後に VoiceQualityEval テストを自動実行（`continue-on-error: true`）
  - S1〜S4 の WAV ファイルをアーティファクト `voice-quality-eval-wavs`（保持 30 日）としてアップロード
  - CI ページからダウンロードして聴取評価が可能

### リリース前チェックリスト（#55）

- **`docs/release-checklist.md`** を新規作成
  - ビルド・テスト・バージョン確認・配布パッケージの必須チェック項目を一覧化
  - 音声品質評価セクション（WAV 生成手順・S1〜S4 採点表・合否基準）を追加
  - リリース前に全チェックボックスを確認する運用を明文化

### 利用方法（音声品質評価）

```
# CI で自動生成されるアーティファクトを利用する場合:
# 1. openjtalk-engine-test.yml を手動実行（workflow_dispatch）
# 2. Actions ページから voice-quality-eval-wavs をダウンロード
# 3. S1.wav〜S4.wav を聴取して docs/release-checklist.md に採点を記入

# ローカルで直接実行する場合:
$env:VOICE_EVAL_OUTPUT_DIR = "C:\temp\voice-eval"
dotnet test TxtToVoice.Tests/TxtToVoice.Tests.csproj --filter "Category=VoiceQualityEval"
```
