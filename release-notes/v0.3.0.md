## 音声エンジン多様化リリース — ISpeechEngine 抽象化・WinRT OneCore 音声対応

---

### インストール方法

1. `TxtToVoice-v0.3.0-win-x64.zip` をダウンロード
2. ZIP を任意のフォルダに展開
3. `TxtToVoice.exe` をダブルクリックして起動

> 辞書データ・設定ファイルは引き続き使えます。  
> 音声エンジンの設定は「ファイル → 設定」から変更できます（変更は次回起動時に適用）。

---

### 変更内容

**1. ISpeechEngine 抽象化（backlog #31）**

`SpeechService` が `System.Speech.Synthesis.SpeechSynthesizer` に直接結合していた構造を解消しました。

```
変更前:
  SpeechService → SpeechSynthesizer（直接依存）

変更後:
  SpeechService → ISpeechEngine（インターフェース）
                      ├── SystemSpeechEngine（System.Speech、現行互換）
                      └── WinRtSpeechEngine（WinRT OneCore、新規）
```

- `ISpeechEngine` インターフェースを新設（`Services/ISpeechEngine.cs`）
- `SystemSpeechEngine` を切り出し（`Services/SystemSpeechEngine.cs`）
- `SpeechService` を薄いアダプタに変更（UI スレッドへのイベント転送と `SaveToFileAsync` の非同期ラップを担当）
- `AppSettings.speechEngineType` フィールドを追加（既定値: `"SystemSpeech"`）
- `AppSettingsService.ReadEngineType()` 静的メソッドを追加（起動時の先読みに使用）

**2. WinRT 音声エンジン実装（backlog #32）**

`Windows.Media.SpeechSynthesis`（WinRT API）を使う `WinRtSpeechEngine` を実装しました。
端末に導入済みの OneCore 系音声（Haruka-Mobile 等、システムの読み上げ音声に準じる）を利用できます。

| 項目 | 内容 |
|---|---|
| 必要 OS | Windows 10 Build 19041 (2004) 以降 |
| 音声品質 | 端末の OneCore 音声に依存（SAPI より自然な場合がある） |
| 読み上げ進捗 | `SpeechSynthesisStream.Timelines`（単語境界タイミング）を使い 50ms ポーリングで追跡 |
| 音声ファイル保存 | WinRT 合成 → WAV ストリーム → NAudio でエンコード（MP3/MP4） |
| 速度変換 | SAPI -10..10 → WinRT SpeakingRate 0.5..3.0（リニアマッピング） |

**既知の制限:**
- 読み上げ開始イベントは WinRT 合成が完了してメディア再生が始まるタイミングで発火するため、
  ボタン押下から「読み上げ中」表示まで SAPI より短い遅延が発生する場合があります。
- 音声の名前は SAPI と異なります（例: `"Microsoft Haruka"` vs `"Microsoft Haruka Desktop"`）。
  エンジンを切り替えた場合は起動後に音声を再選択してください。

**3. 設定ダイアログに音声エンジン選択 UI を追加**

「ファイル → 設定」ダイアログに「音声エンジン」セクションを追加しました。

```
◉ Windows SAPI (System.Speech) — 既定、従来の音声（Haruka 等）
○ Windows WinRT (OneCore) — OneCore 系高品質音声を使用
```

変更は次回起動時に適用されます（現在の読み上げ中は即時切替は行われません）。

**4. TargetFramework を `net8.0-windows10.0.19041.0` に更新**

WinRT API を利用するため、ターゲットフレームワークを更新しました。
アプリの動作要件は Windows 10 2004 以降となります（旧来の SAPI エンジンのみ使用する場合も同様）。
